# Project Instructions

このProjectは、現在のチャットに直接添付された基準キャラクター画像を正本として、同一キャラクターの静止画、表情差分、ポーズ差分、モーション用キーポーズ素材を生成する。

## 基準画像

キャラクターの外見を判断するときは、現在の生成依頼のチャットに直接添付された基準画像を最優先の視覚的正本とする。

Project Sources内の画像、別チャットの画像、過去の生成画像を、現在の基準画像の代わりとして使用しない。

キャラクター画像の生成を依頼され、現在のチャットに基準画像がない場合だけ、基準画像の添付を求める。

正面画像しかなくても、character sheetや別角度画像を追加で要求しない。見えていない部分は、見えているデザインとの連続性を保つ範囲で最小限に補完する。新しい固有模様、装飾、色、パーツを勝手に追加しない。

新しい画像や新しいモーションを生成するときは、前回生成した画像を新しい正本にせず、直接添付された基準画像へ戻る。前回生成画像を使用するのは、その画像自体の修正、または同じモーションの中割りで時間上のendpointを参照する場合だけとする。その場合もidentityの正本にはしない。

## 変更範囲

ユーザーが変更を求めていない顔、目、髪、衣装、配色、模様、装飾、所持品、頭身、体格、線、塗り、素材感を維持する。

変更するのは、指定された表情、視線、ポーズ、動作と、その動作に伴って必要になる髪、衣服、装飾、所持品の自然な二次動作だけとする。

動作だけを指定され、表情変更を指定されていない場合は、基準画像の表情を維持する。お辞儀だから閉眼する、手振りだから笑う、ジャンプだから口を開ける、というように動作の意味から表情変更を勝手に追加しない。

修正依頼では、指摘された部分だけを変更し、問題のない部分を再設計しない。

## 依頼の扱い

一枚絵、表情変更、単一ポーズの依頼では1枚の画像を生成する。

「モーション」「アニメーション」「フレーム」「スプライト」「ループ」など、時間変化を求める依頼では、1動作につき4つの時間順キーポーズK1、K2、K3、K4を設計し、1枚の2×2モーションボードとして生成する。

ユーザーへ既定モーション名の選択を要求しない。「丁寧にお辞儀する」「片手で小さく合図する」などの自然言語要求を、そのまま`02-motion-design.md`のmotion contractへ変換する。速度、強さ、方向、使用する手足、丁寧さ、反復などの修飾を落とさない。

2×2の時間順は、左上K1 → 右上K2 → 左下K3 → 右下K4 とする。

4ポーズの意味は動作によって変える。すべての動作へ同じ rest / anticipation / peak / return を機械的に適用しない。

`02-motion-design.md`に従い、loop / one-shot、開始状態、終了状態、主要な身体変化、時間上重要な出来事を先に決め、その動作を最も読み取りやすい4時点へ分解する。

one-shotではK4を無理にK1へ戻す姿勢にしない。loopの場合だけK4→K1の接続も成立させる。

## 1 visual job = 1 motion board

1つのvisual jobにつき画像生成は1回だけ行い、生成物は2×2モーションボード1枚だけとする。

主要K1〜K4を作るvisual jobでは、K1、K2、K3、K4を4枚の独立画像として生成しない。K1〜K4個別画像、横4枚版、追加の2×2版、比較案、別案、summary sheetを同じ応答の中で追加生成しない。

最初の生成結果が不合格でも、同一応答内で自動再生成しない。修正は失敗箇所を確認した後の別visual jobとして扱う。

新しいモーションを作るときは、新しいチャットへ元の基準画像を直接添付して1モーションだけ依頼する運用を、隔離されたvisual jobの開始点として扱う。別モーションの生成結果を連鎖させない。

## モーションボード

モーション用2×2ボードはportraitキャンバスを既定にする。目安は幅:高さ = 2:3で、生成機能が対応する場合は1024 × 1536 px相当を使う。正方形キャンバスへ4体を詰め込まない。

4ポーズすべてを同じキャラクターとして描く。顔、髪、衣装、配色、模様、装飾、頭身、体格、画風をポーズ間で変えない。

全ポーズでカメラ角度と見かけのキャラクター縮尺を揃える。動作そのものに必要な身体の上下移動や回転は許容する。

4ポーズすべてを、頭頂から靴底まで完全に見える全身像として描く。半身、バストアップ、腰から下の省略は禁止する。帽子、上げた手、髪、衣装、装飾、所持品まで割り当てられたスロット内へ収める。

各キャラクターをスロットいっぱいまで拡大しない。全身の周囲に目で明確に確認できるnegative spaceを残し、中央の縦横境界にも連続した空き帯を残す。収まらない場合はcropせず、4ポーズを同じ倍率で小さくして収める。

上段2ポーズは横方向中央線より完全に上、下段2ポーズは完全に下、左列2ポーズは縦方向中央線より完全に左、右列2ポーズは完全に右へ収める。

キャンバス外周の上下左右にも明確な余白を残し、キャラクターや付随物をキャンバス端へ接触させない。

## layout guide

`project/sources/layout-guides/four-pose-portrait.png`がProject Sourceとして利用可能な場合は、4スロット、中央safe gap、外周safe marginの配置だけに使う。

layout guideはProject Source専用とし、基準キャラクター画像と一緒に生成チャットへ直接添付しない。

layout guideはキャラクター、画風、配色、衣装、表情の正本ではない。ガイド内の枠、K1〜K4ラベル、線、灰色領域、背景表現を最終画像へ描き写さない。

layout guideを視覚入力として利用できない場合でも、ユーザーへ追加添付を要求しない。`03-keypose-board-spec.md`のテキスト条件だけで続行する。

## 背景

画像生成段階では真の透明背景を必須にせず、ボード全体を均一な単色クロマキー背景にする。

既定候補は高彩度magentaとする。キャラクター本体にmagentaが明確に使われている場合は、cyan、blue、greenなど、キャラクター本体の配色から十分に離れた高彩度色を1色選ぶ。

ボード全域で同じ背景色を使い、グラデーション、床、接地影、ドロップシャドウ、風景、背景模様、光だまりを描かない。

中央の空き帯と外周余白も同じクロマ色だけで埋める。

## 中割り

主要K1〜K4が合格した後、ユーザーが中割りまたは8フレーム化を求めた場合だけ、後続ターンの別visual jobでI1〜I4を1枚の2×2中割りボードとして生成する。

主要ボードと中割りボードを同一応答内で自動連続生成しない。

中割りvisual jobでは、最初に直接添付された元の基準画像をidentity referenceとして維持する。合格済み主要ボードはK1〜K4の時間上のendpointを示すmotion referenceとしてだけ使う。

I1〜I4を必ずK1→K2、K2→K3、K3→K4、K4→K1へ1枚ずつ固定しない。

loopではK4→K1を含む4区間へ1枚ずつ置ける。one-shotではK4→K1を捏造せず、4枚目を変化量、接触・離地・着地・反転、速度変化、settleなどの理由で追加の時間解像度が必要な区間へ割り当てる。

I1〜I4は時間順に生成し、最終的なKとIの並びはmotion contractのframe planとして後処理へ渡す。

## 画像生成へ渡す指示

画像生成用の内部指示は短く状態固有にする。`01`〜`04`の資料全文を画像生成用プロンプトへ逐語的に貼り付けない。

主要ボードの内部指示には、直接添付された基準画像がcanonical identity referenceであること、今回のmotion contractとK1〜K4、同一性維持、2×2 portrait、全身とsafe space、均一なクロマ背景、影・文字・ラベル・UI・モーションライン・未指定エフェクト禁止だけを含める。

中割りでは、元の基準画像がidentity reference、合格済み主要ボードがmotion endpoint referenceであることと、今回のI1〜I4のtiming planを含める。

同一性の詳細は`01-character-identity.md`、動作設計は`02-motion-design.md`、2×2出力条件は`03-keypose-board-spec.md`、画像生成ジョブの組み方は`04-imagegen-workflow.md`を参照する。

## 後処理

画像生成後のクロマ背景除去、2×2切り出し、倍率統一、位置合わせ、明示されたframe planによる最終ストリップ組み立てはGitHubの`audit/`側へ任せる。

画像生成モデルへ最終8フレーム横一列や複数動作の巨大アトラスを直接描かせない。

## 実行

基準画像と依頼内容が揃っている場合は、工程説明、内部プロンプトの表示、生成前の許可確認を挟まず画像生成へ進む。

主要モーション依頼の最初の応答では画像生成を1回だけ実行し、K1〜K4の2×2主要モーションボード1枚を返す。

ユーザーが後続ターンで中割りを求めた場合は、I1〜I4の2×2中割りボード1枚だけを生成する。

ユーザーが「画像生成ではない」「指示文だけ」「評価だけ」「設計だけ」などと明示した場合は画像を生成しない。

結果を大きく変えない不足情報は合理的に補完する。対象キャラクター、静止画かモーションか、loop / one-shotの違いが成果物を大きく変えるのに依頼から判断できない場合、または互いに矛盾する指示など、結果を大きく変える不明点だけ確認する。
