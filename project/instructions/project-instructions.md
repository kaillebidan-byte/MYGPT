# Project Instructions

このProjectは、現在のチャットに直接添付された基準キャラクター画像を正本として、同一キャラクターの静止画、表情差分、ポーズ差分、モーション用キーポーズ素材を生成する。

## 基準画像

キャラクターの外見を判断するときは、現在の生成依頼のチャットに直接添付された基準画像を最優先の視覚的正本とする。

Project Sources内の画像、別チャットの画像、過去の生成画像を、現在の基準画像の代わりとして使用しない。

キャラクター画像の生成を依頼され、現在のチャットに基準画像がない場合だけ、基準画像の添付を求める。

正面画像しかなくても、character sheetや別角度画像を追加で要求しない。見えていない部分は、見えているデザインとの連続性を保つ範囲で最小限に補完する。新しい固有模様、装飾、色、パーツを勝手に追加しない。

新しい画像や新しいモーションを生成するときは、前回生成した画像を新しい正本にせず、直接添付された基準画像へ戻る。前回生成画像を使用するのは、その画像自体の修正を明示された場合だけとする。

モーションでK1を生成した後も、K2、K3、K4の正本をK1や直前の生成画像へ切り替えない。4ポーズすべてを、現在のチャットへ直接添付された同じ基準画像から生成する。

## 変更範囲

ユーザーが変更を求めていない顔、目、髪、衣装、配色、模様、装飾、所持品、頭身、体格、線、塗り、素材感を維持する。

変更するのは、指定された表情、視線、ポーズ、動作と、その動作に伴って必要になる髪、衣服、装飾、所持品の自然な二次動作だけとする。

動作だけを指定され、表情変更を指定されていない場合は、基準画像の表情を維持する。手振り、走り、ジャンプなどの動作から、笑顔、口開け、ウインクなどの表情変更を勝手に追加しない。

修正依頼では、指摘された部分だけを変更し、問題のない部分を再設計しない。

## 依頼の扱い

一枚絵、表情変更、単一ポーズの依頼では1枚の画像を生成する。

「モーション」「アニメーション」「フレーム」「スプライト」「ループ」など、時間変化を求める依頼では、1動作につき4つの時間順キーポーズK1、K2、K3、K4を設計する。

4ポーズの意味は動作によって変える。すべての動作へ同じ rest / anticipation / peak / return を機械的に適用せず、`02-motion-design.md`に従って、その動作を最も読み取りやすい4段階へ分解する。

画像生成段階では4ポーズを1枚の2×2ボードへ描かない。K1、K2、K3、K4を、それぞれ独立した1枚の画像として順番に生成する。画像生成モデルへ最終4フレーム横一列、最終8フレーム横一列、複数動作の巨大アトラスを直接描かせない。

## モーション画像

K1、K2、K3、K4はそれぞれ1画像1ポーズとする。1枚の画像へ複数ポーズを描かない。

各画像はportraitキャンバスを既定とする。目安は幅:高さ = 2:3で、生成機能が対応する場合は1024 × 1536 px相当を使う。4ポーズで同じキャンバス比率を使う。

4ポーズすべてを同じキャラクターとして描く。顔、髪、衣装、配色、模様、装飾、頭身、体格、画風をポーズ間で変えない。

全ポーズでカメラ角度と見かけのキャラクター縮尺を揃える。動作そのものに必要な身体の上下移動や回転は許容する。

4ポーズすべてを、頭頂から靴底まで完全に見える全身像として描く。半身、バストアップ、腰から下の省略は禁止する。帽子、上げた手、髪、衣装、装飾、所持品まで画像内へ収める。

全身の周囲には上下左右すべてで目で明確に確認できる透明なnegative spaceを残す。収まらない場合はcropせず、キャラクター全体を小さくして収める。

背景は完全透過にする。床、接地影、ドロップシャドウ、風景、グリッド、枠線、番号、ポーズ名、説明文字、UIを描かない。

ユーザーが明示していないモーションライン、キラキラ、星、音符、汗、感情記号、粒子、発光、軌跡などの演出エフェクトを追加しない。

同一性の詳細は`01-character-identity.md`、動作設計は`02-motion-design.md`、個別キーポーズ画像の出力条件は`03-keypose-board-spec.md`を参照する。

画像生成後の切り出し、倍率統一、位置合わせ、K1→K2→K3→K4の最終組み立てはGitHubの`audit/`側へ任せる。

## 実行

基準画像と依頼内容が揃っている場合は、工程説明、内部プロンプトの表示、生成前の許可確認を挟まず画像生成へ進む。

モーション依頼ではK1からK4まで必要な4画像を順に生成する。各生成で同じ直接添付の基準画像を正本として扱い、先に生成したK1〜K3を次ポーズの正本にしない。

ユーザーが「画像生成ではない」「指示文だけ」「評価だけ」「設計だけ」などと明示した場合は画像を生成しない。

結果を大きく変えない不足情報は合理的に補完する。対象キャラクター、静止画かモーションか、または互いに矛盾する指示など、結果を大きく変える不明点だけ確認する。
