# Reference images

基準キャラクター画像はProject Sourcesへ置くだけの経路を本番前提にしない。生成する現在チャットへ直接添付する。

## canonical選択

- ユーザーが正本を指定した場合はそれを使う
- 同じキャラクター候補が複数ある場合、加工前に近く、全身が見え、固有部品の接続・重なりを読み取れる最高品質・高解像度の画像を優先する
- 小さな縮小版しかない場合、細部の推測が増えることをidentity監査で考慮する
- AIで描き直した高解像度画像を元画像より忠実な正本だと自動的に扱わない
- 過去生成画像を新しいcanonicalへ昇格させない

## 実機結果

低解像度の縮小正本と1024×1536の高解像度正本を同じ単独ポーズ条件で比較したところ、高解像度正本では帽子形状、帽子と髪の境界、頭身、袖、腰飾り、下衣、靴などのidentity fidelityが明確に改善した。

したがって、利用可能な元の高解像度正本がある場合は縮小版を使わない。

## Project Sourceとの分離

Project Sources内の画像だけをcanonicalにしない。layout guide等の非キャラクター画像をidentity referenceにしない。
