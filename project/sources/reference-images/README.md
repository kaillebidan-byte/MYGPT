# Reference images

基準キャラクター画像は、Project Sourcesへ置くだけの参照経路を本番前提にしない。

生成時は、現在のチャットへ正本の基準画像を直接添付する。

## 現在の運用

- 正本は既存の正面基準画像を使う
- character sheetや未設定の別角度画像を必須にしない
- Project Sources内の画像だけを正本としてモーション生成しない
- 新しい生成では前回生成画像を正本にせず、元の基準画像へ戻る
- 前回生成画像を使うのは、その画像自体の修正を依頼するときだけ

## 理由

Project Sourcesへ基準画像を置くだけの実機試験では、静止画は生成できた一方、モーション生成時に基準画像の参照が切れ、別キャラクターが生成された。

そのため、画像はProject Sourcesのテキスト資料と同じ信頼経路として扱わない。

このフォルダには画像そのものを必須保存せず、参照画像の運用方針や将来の比較試験だけを記録する。
