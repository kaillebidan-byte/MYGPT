# Keypose Board Specification

この資料は、画像生成段階の2×2キーポーズボードだけを定義する。

最終フレーム画像、最終スプライトシート、アトラスのピクセル寸法や後処理方法は定義しない。

## 基本構成

1枚の画像に1動作だけを描く。

4つの時間順キーポーズを2列×2行へ配置する。

- 左上: K1
- 右上: K2
- 左下: K3
- 右下: K4

キャンバス上にグリッド線は描かない。位置関係だけを2×2として扱う。

## キャンバス比率

モーション用2×2ボードは正方形を既定にしない。

各象限が縦長になるportraitキャンバスを使う。既定の目安は幅:高さ = 2:3で、生成機能が対応する場合は1024 × 1536 px相当を選ぶ。

1024 × 1536 pxの2×2なら、各象限は論理上512 × 768 px相当になる。

生成機能が厳密なピクセル値を指定できない場合も、利用可能なportrait比率のうち2:3に近いものを選び、正方形キャンバスへ4体を詰め込まない。

このportrait指定の目的は、縦長の全身キャラクター、上げた手、中央透明帯、外周余白を同時に確保することである。ピクセル値そのものより、各象限に十分な縦方向の空間を持たせることを優先する。

## 各ポーズ

各象限には同じキャラクターを1体だけ描く。

4体は同じ衣装、顔、髪、配色、装飾、画風、カメラ角度、見かけの縮尺を共有する。

4ポーズすべてを、頭頂から靴底まで完全に見える全身像として描く。半身、バストアップ、腰から下の省略は禁止する。

全身が象限へ収まらない場合は、身体の一部を切るのではなく、4ポーズを同じ倍率で小さくして全身と付随物を収める。特定のポーズだけ別倍率にしない。

各キャラクターを象限いっぱいまで拡大しない。帽子や上げた手を含む全身の周囲に、目で明確に確認できる透明なnegative spaceを残す小さめの全身像として配置する。

ポーズによって必要な身体位置の変化は許容するが、キャラクターをフレームごとに拡大・縮小しない。

4体を互いに重ねない。

## 切り出し余白

2×2の中央を通る縦方向と横方向の仮想境界には、キャンバス全体を横断する連続した透明帯を必ず残す。

帽子、髪、耳、角、手、足、衣服、尾、翼、装飾、所持品を中央の透明帯へ侵入させない。

上段2ポーズは横方向中央線より完全に上、下段2ポーズは完全に下、左列2ポーズは縦方向中央線より完全に左、右列2ポーズは完全に右へ収める。

各ポーズは割り当てられた象限の内部だけに存在し、中央線をまたがない。収まらない場合はcropせず、4ポーズすべてを同じ倍率でさらに小さくする。

キャンバス外周にも、上下左右すべてで目で明確に確認できる透明余白を残す。キャラクター本体、髪、帽子、手足、衣装、装飾、所持品をキャンバス端へ接触させない。

上段のポーズでも脚や靴まで表示し、下段のポーズでも頭頂や上げた手まで表示する。象限境界やキャンバス端をトリミング位置として使わない。

## 背景

背景は完全透過とする。

床、影、風景、装飾背景は、ユーザーが明示的に要求した場合だけ加える。

透過を示すチェック柄を画像そのものへ描かない。

## 描かないもの

- グリッド
- 枠
- 番号
- K1などのラベル
- 矢印
- 説明文
- UI
- チェック柄の透過表現
- モーションライン
- キラキラ、星、音符、汗などの感情・動作記号
- 粒子、発光、軌跡などの未指定エフェクト

ユーザーが明示的に要求していない演出要素を、動作の説明目的で追加しない。

## 時間順

4ポーズの意味は`02-motion-design.md`で決める。

この資料では、K1 → K2 → K3 → K4が時間順であることだけを固定する。

## 8フレーム化

最終8フレームが必要でも、最初の画像へ8体を直接描かない。

まず4つの主要キーポーズをこの仕様で生成する。

必要な中割りは、主要キーポーズとは別の2×2ボードとして生成する。

中割りボードも4つを時間順に配置し、各ポーズを独立して切り出せる余白と同一性を維持する。

最終的な切り出し、倍率統一、位置合わせ、フレーム配置は画像生成後の処理へ任せる。

`audit/scripts/build_motion_strip.py`は入力ボードを正方形へ固定していない。幅と高さが2列×2行で割り切れるボードを分割するため、portrait 2×2ボードをそのまま後処理へ渡せる。

## 生成段階の合格条件

- ボード全体がportraitで、各象限が縦長である
- 正方形キャンバスへ4体を詰め込んでいない
- 4象限に1ポーズずつある
- K1 → K2 → K3 → K4の順に動作が読める
- 4ポーズが同じキャラクターとして読める
- 顔、髪、衣装、配色、装飾が共通している
- カメラ角度と見かけの縮尺が揃っている
- 4ポーズすべてで頭頂から靴底まで見える
- 各キャラクターの周囲に明確なtransparent negative spaceがある
- 全身と付随物が切れていない
- 中央の縦横境界を横断する連続した透明帯がある
- どのポーズも中央線をまたいでいない
- キャンバス外周の上下左右すべてに明確な透明余白がある
- キャラクターや付随物がキャンバス端へ接触していない
- 背景が透明である
- 枠、番号、文字、UIがない
- 未指定のモーションライン、記号、粒子、発光などのエフェクトがない
