# Keypose Source Specification

この資料は、モーション用キーポーズを画像生成する段階の出力条件を定義する。

最終フレーム画像、最終スプライトシート、アトラスのピクセル寸法や後処理方法は定義しない。

## 基本構成

1動作につき4つの時間順キーポーズを用意する。

- K1
- K2
- K3
- K4

画像生成段階では4ポーズを1枚の2×2ボードへ描かない。

K1、K2、K3、K4をそれぞれ独立した画像として生成し、1画像には1ポーズのキャラクターだけを描く。

4画像の時間順はK1 → K2 → K3 → K4とする。K1などのラベル、番号、説明文を画像そのものへ描かない。

## 基準画像

4ポーズすべてについて、現在のチャットへ直接添付された同じ基準キャラクター画像を視覚的正本とする。

K1生成後にK1をK2の正本へせず、K2生成後にK2をK3の正本へしない。先に生成されたモーション画像が会話中に存在していても、それを次ポーズのキャラクターデザイン基準として使わない。

前回生成画像を使用するのは、その画像自体を修正するようユーザーが明示した場合だけとする。

## キャンバス

各キーポーズ画像にはportraitキャンバスを使う。

既定の目安は幅:高さ = 2:3で、生成機能が対応する場合は1024 × 1536 px相当を選ぶ。

K1〜K4で同じキャンバス比率を使用する。

portrait指定の目的は、全身、上げた手、帽子、衣装、装飾を十分な解像度で保持しながら、外周に透明余白を確保することである。

## 各ポーズ

1画像には同じキャラクターを1体だけ描く。

4ポーズは同じ衣装、顔、髪、配色、模様、装飾、体格、画風、カメラ角度、見かけの縮尺を共有する。

4ポーズすべてを、頭頂から靴底まで完全に見える全身像として描く。半身、バストアップ、腰から下の省略は禁止する。

帽子、髪、耳、角、上げた手、足、衣服、尾、翼、装飾、所持品まで画像内へ完全に収める。

全身が画像へ収まらない場合は身体の一部を切らず、キャラクター全体を小さくして収める。

ポーズによって必要な身体位置の変化は許容するが、キャラクターの頭身、胴体形状、胸部を含む体格そのものを変えない。

全身の周囲には、上下左右すべてで目で明確に確認できる透明なnegative spaceを残す。キャラクターや付随物をキャンバス端へ接触させない。

## 背景

背景は完全透過とする。

床、接地面、接地影、ドロップシャドウ、風景、装飾背景は、ユーザーが明示的に要求した場合だけ加える。

透過を示すチェック柄を画像そのものへ描かない。

## 描かないもの

- 2×2グリッド
- 複数ポーズ
- 枠
- 番号
- K1などのラベル
- 矢印
- 説明文
- UI
- チェック柄の透過表現
- 床や接地影
- モーションライン
- キラキラ、星、音符、汗などの感情・動作記号
- 粒子、発光、軌跡などの未指定エフェクト

ユーザーが明示的に要求していない演出要素を、動作の説明目的で追加しない。

## 時間順

4ポーズの意味は`02-motion-design.md`で決める。

この資料では、K1 → K2 → K3 → K4が時間順であることだけを固定する。

## 8フレーム化

最終8フレームが必要でも、画像生成モデルへ8体を1枚に直接描かせない。

まずK1〜K4を4枚の独立画像として生成する。

必要な中割りも、1画像1ポーズの独立画像として生成する。中割り生成時も現在のチャットへ直接添付された元の基準画像をキャラクター正本とし、先に生成したポーズ画像を新しい正本にしない。

最終的な切り出し、倍率統一、位置合わせ、フレーム配置は画像生成後の処理へ任せる。

## audit入力

本番経路では、`audit/scripts/build_motion_strip.py`へK1、K2、K3、K4の4画像を時間順に個別入力する。

`--keypose-images K1 K2 K3 K4`を使用し、画像生成モデルに2×2ボードを組み立てさせない。

既存の2×2ボード入力は過去素材との互換用として残すが、新しい画像生成の本番経路では使用しない。

中割り4画像を使う場合は`--inbetween-images I1 I2 I3 I4`として個別入力する。

## 生成段階の合格条件

- K1〜K4が4枚の独立画像として生成されている
- 1画像に1ポーズだけ存在する
- 各画像がportraitである
- K1 → K2 → K3 → K4の順に動作が読める
- 4ポーズが同じキャラクターとして読める
- 顔、髪、衣装、配色、模様、装飾、体格が共通している
- カメラ角度と見かけの縮尺が揃っている
- 4ポーズすべてで頭頂から靴底まで見える
- 全身と付随物が切れていない
- 各画像の上下左右に明確な透明余白がある
- キャラクターや付随物がキャンバス端へ接触していない
- 背景が完全透過である
- 床、接地影、ドロップシャドウがない
- 枠、番号、文字、UIがない
- 未指定のモーションライン、記号、粒子、発光などのエフェクトがない
