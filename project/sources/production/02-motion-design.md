# Motion Design

この資料は、ユーザーが自然言語で指定した動作を4つの主要キーポーズへ分解するための規則を定義する。

モーション名の一覧へ依頼を当てはめる資料ではない。`waving`、`running`、`jumping`などの既知名称がなくても、ユーザーの依頼文そのものから時間構造を設計する。

4ポーズは左上K1 → 右上K2 → 左下K3 → 右下K4の時間順とする。

rest / anticipation / peak / return をすべての動作へ固定適用しない。

## 1. ユーザー要求をmotion contractへ変換する

画像生成前に、依頼文から今回だけのmotion contractを内部的に決める。

最低限、次を決める。

- `action`: 何をする動作か。動作名だけでなく「丁寧に」「素早く」「小さく」「右手で」などの修飾も保持する
- `mode`: `loop` または `one-shot`
- `start`: 動作開始時の身体状態
- `end`: 動作終了時の身体状態
- `primary motion`: 主に動く身体部位、重心、身体軸、進行方向
- `key events`: 最大変化、接地、離地、接触、反転、停止など時間上重要な出来事
- `expression policy`: 表情変更の指定があるか。指定がなければ基準表情を維持する
- `K1`〜`K4`: 上記を最も少ない飛躍で表せる4つの主要時点
- `transitions`: K1→K2、K2→K3、K3→K4と、loopの場合だけK4→K1のつながり

motion contract自体をユーザーへ長文で表示する必要はない。画像生成用の短い状態指示へ圧縮して使う。

## 2. loop / one-shot の判断

ユーザーがloop、繰り返し、1回だけ、往復などを明示した場合はそれを優先する。

明示がない場合は動作の意味から判断する。

- 継続的な歩行・走行・待機・反復ジェスチャーなど、周期として読むのが自然な動作はloopとして扱える
- お辞儀、着地、拾う、座る、攻撃するなど、完了状態が自然に存在する動作はone-shotを既定とする
- loopとone-shotのどちらでも自然で、選択によってK4や最終成果物が大きく変わる場合だけ確認する

loopを選んだ場合はK4→K1へ自然につながることを要求する。

one-shotではK4を無理にK1へ戻す姿勢にしない。ユーザーの依頼として自然な終了状態をK4へ置く。

## 3. K1〜K4の選び方

K1〜K4は等時間隔である必要はない。動作を読み取るために重要な時点を優先する。

- K1は時間上最初の主要状態
- K4は時間上最後の主要状態
- K2とK3は、K1からK4の間で動きの方向、重心、接触状態、身体軸、手足の配置などが最もよく分かれる時点を選ぶ
- 隣り合う2ポーズの間で身体がどう移動したか推測できるようにする
- 顔だけ、手首だけなどの小さすぎる差で4枠を消費しない
- 同じ姿勢の複製で枠数を満たさない

必要に応じて重心、肩、腰、腕、脚、身体軸まで使って時間変化を見せる。ただしキャラクターの体格、頭身、衣装構造そのものは変えない。

## 4. 表情

動作だけを指定され、表情変更を指定されていない場合は、4ポーズすべてで基準画像の表情を維持する。K1〜K4すべてで同じ表情方針を適用する。

お辞儀だから目を閉じる、手を振るから笑う、ジャンプだから口を開ける、というように動作の意味から表情演技を自動追加しない。

表情そのものが動作の主題である場合、またはユーザーが表情変化を明示した場合だけ、motion contractへ表情変化を含める。

## 5. 二次動作とカメラ

髪、衣服、尾、ケーブル、札、所持品などは、身体の加速・減速に応じて自然に追従させてよい。

二次動作を理由に固有パーツを消したり、数・接続位置・左右関係を変えたりしない。

カメラ移動、ズーム、フレームごとの画角変更で動作を表現しない。

## 6. 中割り用timing plan

主要K1〜K4が確定した後で中割りが必要な場合は、各区間へ必要な補助フレーム数をmotion contractから決める。

基本区間は次の3つ。

- K1→K2
- K2→K3
- K3→K4

loopの場合だけ、4つ目としてK4→K1を追加する。

8フレーム化では4枚の中割りI1〜I4を作れるが、one-shotでI4をK4→K1へ置く必要はない。3区間のうち、変化量が大きい、速度変化が大きい、接触・離地・着地・反転がある、またはsettleを丁寧に見せる必要がある区間へ追加の1枚を割り当てる。

I1〜I4は時間順に並べる。どのK間へ入るかはmotion contractのtiming planで決め、最終frame orderを後処理へ渡す。

## 7. 品質条件

4ポーズのシルエットだけを見ても時間変化が区別できることを優先する。

次を避ける。

- 同じ姿勢を複製しただけの4枚
- one-shotなのにK4を無理にK1へ戻す構成
- loopなのにK4→K1が不連続な構成
- フレームごとのカメラ変更
- 関節の不連続な反転
- 固有パーツの消失や左右反転
- 状態として読めない小さすぎる変化
- 動作の説明目的だけで追加された笑顔、閉眼、口開け、モーションライン、記号、エフェクト
