# Motion Design

モーション画像では、同じ姿勢を4枚並べるのではなく、時間変化が明確に読み取れる4つの主要姿勢を選ぶ。

4ポーズは左上 → 右上 → 左下 → 右下の時間順とする。

4段階の意味は動作ごとに決める。rest / anticipation / peak / return をすべての動作へ固定適用しない。

## 共通原則

隣り合う2ポーズの間に、身体がどう動いたか推測できること。

ポーズ差は、顔だけや手首だけの微差ではなく、必要に応じて重心、肩、腰、腕、脚、身体軸まで使って読み取れるようにする。ただしキャラクターの体格そのものは変えない。

髪、衣服、尾、ケーブル、札、所持品などは、身体と完全同期させず、加速・減速に少し遅れて追従させる。

カメラを動かして動作を表現しない。

ループ動作では4枚目から1枚目へ戻る流れも不自然にしない。

## waving / 手を振る

- K1: 腕を自然に下ろした開始姿勢
- K2: 肩と肘を使って腕を上げ始める
- K3: 手が最も高い、または最も外側へ振れた明確な手振り姿勢
- K4: 腕を下げ始め、K1へ戻れる姿勢

手だけを別位置へ貼り付けたようにせず、肩、肘、上半身へ小さな連動を加える。

## idle / 待機

- K1: 落ち着いた基準姿勢
- K2: 呼吸や重心移動が始まる
- K3: 呼吸または揺れが最も大きい姿勢
- K4: 基準姿勢へ落ち着き始める

待機モーションとして読める範囲に留め、大げさなジェスチャーを追加しない。

## running-right / running-left / 走る

走行は静止 → 予備 → 頂点 → 戻りとして扱わない。歩容の主要位相を選ぶ。

- K1: 接地が明確な姿勢
- K2: 沈み込み、荷重、蹴り出し
- K3: 脚が交差または通過する中間姿勢
- K4: 浮遊または次の接地へ向かう回復姿勢

腕と脚を逆相で動かし、重心の上下変化を作る。

左右非対称の衣装や装飾を、進行方向変更のために単純反転しない。

## jumping / 跳ぶ

- K1: 通常姿勢
- K2: しゃがみ込み・予備動作
- K3: 空中で最も高い姿勢
- K4: 着地または着地直前

ジャンプの高さを、キャラクター自体の縮尺変更で表現しない。

## surprised / 驚く

- K1: 通常姿勢
- K2: 刺激へ気づき始める
- K3: 目、肩、手、上半身に最も明確な驚きが出る
- K4: 驚きが収まり始める

顔だけでなく、必要に応じて身体全体へ反応を連動させる。ただし過剰な変形や別人格に見える演技は避ける。

## failed / 失敗・落胆

- K1: 作業または通常姿勢
- K2: 問題に気づく
- K3: 肩、視線、手元に落胆や確認反応が最も出る
- K4: 再確認または待機へ戻り始める

転倒や極端な悲嘆を既定にしない。

## review / 確認

- K1: 対象を見る
- K2: 別の箇所または資料へ視線を移す
- K3: 比較・確認動作が最も明確になる
- K4: うなずく、または確認姿勢へ戻る

読めない文字や不要なUIを新しく描いて状態を説明しない。

## その他の動作

名前だけ指定された場合は、次の4段階をその動作に合わせて設計する。

1. 開始状態
2. 動きが明確になり始める状態
3. その動作を最もよく表す状態
4. 終了または次のループへつながる状態

各ポーズのシルエットだけを見ても時間変化が区別できることを優先する。

同じ姿勢を複製しただけの4枚、フレームごとのカメラ変更、関節の不連続な反転、固有パーツの消失、状態として読めない小さすぎる変化を避ける。
