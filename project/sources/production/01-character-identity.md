# Character Identity

この資料は、現在のチャットへ直接添付された基準画像から維持すべきキャラクター同一性を判断するための基準である。特定キャラクターの設定表ではない。

基準画像そのものより、この文書を優先してはいけない。

## canonical image

画像生成では、現在チャットへ直接添付された正本画像をidentity anchorとする。

同じキャラクターの候補画像が複数ある場合は、ユーザーが正本と明示したものを優先する。明示がなければ、加工前に近く、全身が見え、解像度が高く、固有部品の接続や重なりを読み取りやすい画像を優先する。

低解像度画像をAIで描き直した画像を、元画像より忠実な正本だと自動的に扱わない。過去生成画像、別チャットの画像、Project Sources内の画像をcanonicalへ昇格させない。

## identity contract

生成前または監査時に、canonicalから次を読む。

- `proportions`: 頭身、頭・胴・腕・脚・手足の比率、体格
- `silhouette`: 頭部、帽子、髪、胴体、袖、下衣、靴などの外形
- `topology`: 固有部品の個数、接続位置、左右関係、重なり順
- `occlusion`: 帽子と髪、髪と顔、袖と手、腰飾りと衣装など、どの部品がどこを覆い、どの境界から見えるか
- `anchors`: 顔、目、髪、頭部品、胸部意匠、腰部意匠、房、紐、留め具、裾、靴など
- `style`: 線、塗り、陰影、素材感、デフォルメの程度

生成promptへこの全文を貼り付ける必要はない。生成側ではcanonical画像を主anchorとし、今回崩れやすい不変条件だけを短く補足する。詳細contractは監査基準として使う。

## 顔・髪・頭部

表情が変わっても顔そのものを別人にしない。目の形、大きさ、間隔、瞳色、顔輪郭、前髪、横髪、後ろ髪、毛先、頭部固有パーツを維持する。

帽子と髪を別々の形として見るだけでなく、帽子が髪を覆う範囲、髪が帽子下縁のどこから見えるかなどの重なり構造を維持する。canonicalにない髪束や垂れ飾りを追加しない。

## 衣装・固有物

衣装の形、袖、襟、裾、靴、配色、模様、縁取り、ベルト、装飾、所持品を維持する。

小さな固有ディテールも省略可能な飾りとして扱わない。胸紋、袖口、腰飾り、房、紐、留め具などの形、個数、接続位置、左右関係、重なりを、ポーズ変更だけを理由に簡略化、統合、増減、左右反転、別形状化しない。

ポーズで隠れた部分は不可視として扱う。見えている構造まで作り直さず、canonicalから見えない裏側へ新しい模様や部品を設定しない。

## 体格

頭身、頭の大きさ、肩幅、胴、胸部、腕、脚、手足の比率を維持する。ポーズによる遠近変化とキャラクターそのものの体格変更を混同しない。

## 複数フレーム

各フレームは同じcanonicalから生成し、前フレームをidentityの新しい正本にしない。

共通させるもの:
- 顔、髪、頭部品
- 衣装、配色、模様
- 固有部品の形、個数、接続、左右関係、重なり
- proportions / silhouette / occlusion
- 画風

変えてよいもの:
- 指定された表情・視線
- 手足、身体の向き、重心
- 動作に伴う髪、衣服、装飾の二次動作

二次動作でも部品構成そのものを変えない。

## repair

失敗フレームを修正するときもcanonicalへ再アンカーする。失敗生成物をidentity正本にしない。修正対象以外を再設計しない。
