# ChatGPT Project configuration

この領域はChatGPT Projectへ投入する指示と参照資料を管理する。

Custom GPT用設定は`legacy/custom-gpt/`へ退避する。

## 構成

- `instructions/project-instructions.md` — Project Instructions欄へ入れる指示
- `sources/production/` — Projectへ追加する本番用の読み物
- `sources/reference-images/` — 基準画像の管理方針

本番用読み物の本文は次段階で作成する。
