# Key-pose motion pipeline

画像生成モデルへ最終スプライトを一度に作らせず、生成と整形を分離する。

## 1. キーポーズボードを生成する

本番GPTへ基準キャラクター画像を添付し、動作を指定する。

生成物は透明背景の2×2ボードとする。

| 位置 | 役割 |
|---|---|
| 左上 | 基準姿勢 |
| 右上 | 予備動作 |
| 左下 | 主動作の頂点 |
| 右下 | 基準姿勢へ戻る途中 |

各象限に1ポーズだけを置き、全身と付随物を切らず、象限境界から十分に離す。

## 2. 4フレームへ組み立てる

```bash
python audit/scripts/build_motion_strip.py keyposes.png \
  --spec audit/specs/motion-keypose-2x2.json \
  --output motion-4f.png \
  --debug-dir motion-debug
```

処理内容:

- 画像を均等な2×2へ分割
- 透明画素から各ポーズの外接矩形を取得
- 空ポーズとセル端接触を拒否
- 全ポーズに共通倍率を適用
- 水平方向をセル中央へ配置
- 下端基準を揃える
- 透明PNGの横一列ストリップを出力
- フレーム順と切り出し情報をJSONへ保存

既定出力は1セル256×320 px、全体1024×320 px。

## 3. 8フレームへ組み立てる

キーポーズ間の中割り4ポーズを、別の透明2×2ボードとして生成する。

| 位置 | 役割 |
|---|---|
| 左上 | 基準→予備 |
| 右上 | 予備→頂点 |
| 左下 | 頂点→戻り |
| 右下 | 戻り→基準 |

```bash
python audit/scripts/build_motion_strip.py keyposes.png \
  --inbetween-board inbetweens.png \
  --spec audit/specs/motion-keypose-2x2.json \
  --output motion-8f.png \
  --debug-dir motion-debug
```

最終順序は、キーポーズと中割りを交互に配置する。

## 4. 禁止する水増し

次の方法を既定処理にしない。

- 同じ画像の複製
- 単純な左右反転
- 透明度だけを変えたクロスフェード
- 4ポーズを往復順に並べただけの8フレーム化

これらはフレーム数を満たしても、動作とキャラクター同一性の品質を改善しない。

## 5. 失敗条件

`build_motion_strip.py`は次の場合に失敗する。

- 入力画像が2×2へ均等分割できない
- 背景が全面不透明
- 空の象限がある
- ポーズが象限端へ近すぎる
- 出力セルへ収まらない

失敗した場合は、最終ストリップを無理に生成せず、該当するキーポーズボードを再生成する。

## 6. 次段階

4フレームまたは8フレームのストリップを作成した後、既存の監査コードで縮尺、セル端、重複、ループ接続を確認する。

複数状態の8×9アトラスは、状態ごとに合格したストリップを得てから後段で組み立てる。
