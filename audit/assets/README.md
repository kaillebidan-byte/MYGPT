# Sprite template assets

## `sprite-template-8x9.svg`

1536×1872 px、8列×9行、1セル192×208 pxの透過レイアウトテンプレート。

SVGを画像入力として受け付けない環境では、`export-template.html`をローカルで開き、透過PNGを書き出す。

## `export-template.html`

ブラウザーで開き、`PNGを保存`ボタンを押すと、同じ8×9テンプレートを透過PNGとして保存できる。

生成時は基準キャラクター画像をデザイン正本、テンプレート画像を配置基準として扱う。テンプレートの枠線は最終画像へ残さない。
