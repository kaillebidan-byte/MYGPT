# Sprite output specification

この文書は、モーション、アニメーション、フレーム列、スプライト、スプライトシートを求められた場合に参照する。

単一の表情差分や一枚絵では参照しない。

## 1. 基本方針

画像生成モデルへ、最終8フレームの横一列スプライトや複数行アトラスを一度に生成させない。

処理を次の段階へ分ける。

1. 4つの大きなキーポーズを2×2で画像生成する
2. 各ポーズを切り出す
3. 同じ倍率で縮小・拡大する
4. 各セルの中央と基準位置を揃える
5. 4フレームのストリップへ配置する
6. 8フレームが必要な場合は、別途生成した4つの中割りを交互に組み込む
7. 最終画像を監査する

同じ画像の複製、単純な左右反転、透明度によるクロスフェードだけでフレーム数を水増ししない。

## 2. 画像生成段階の既定値

ユーザーがモーションを指定し、生成方法を指定していない場合は、次を既定値にする。

- 1動作
- 4キーポーズ
- 2列×2行
- 背景は完全透過
- 1象限につき1ポーズ
- 各象限の外周に十分な余白
- 全ポーズで同じキャラクター縮尺
- 全ポーズで同じカメラ角度
- グリッド線、枠線、番号、説明文字なし

2×2の配置順:

1. 左上: `rest` — 基準姿勢
2. 右上: `anticipation` — 予備動作
3. 左下: `peak` — 主動作の頂点
4. 右下: `return` — 基準姿勢へ戻る途中

## 3. キーポーズの設計

4つのポーズは、動作の違いが明確に読めるようにする。

- `rest`: 動作開始前の基準姿勢
- `anticipation`: 主動作へ入るための予備動作
- `peak`: シルエットが最も大きく変わる主動作の頂点
- `return`: 基準姿勢へ戻る途中で、先頭へ自然につながる姿勢

手を振る動作の例:

1. 腕を自然に下ろす
2. 腕を上げ始める
3. 手を最も高く上げる
4. 腕を下ろし始める

## 4. 2×2ボードの分離条件

各ポーズを機械的に切り出せるようにする。

- キャンバスを均等な2列×2行として扱えること
- 各象限にポーズが一つだけあること
- ポーズが象限境界をまたがないこと
- 頭、髪、耳、角、手、足、尾、翼、所持品を切らないこと
- 各象限の外周へ透明余白を残すこと
- ポーズ同士を重ねないこと
- 背景は完全透過であること

表示上の黒背景は透過表示であれば問題ない。画像データ自体が全面不透明の場合は分離処理の入力にしない。

## 5. 4フレームストリップ

4キーポーズだけを使う場合は、左から次の順で配置する。

1. `rest`
2. `anticipation`
3. `peak`
4. `return`

既定の組み立て仕様:

- 1セル: 256 × 320 px
- 出力: 1024 × 320 px
- 背景: 完全透過
- 基準位置: セル下端から16 px上
- 水平方向: セル中央
- 全フレームで共通倍率を使用

ポーズごとに別々の倍率で全高を揃えない。上げた手や跳躍による自然な外接矩形の差を残し、キャラクター本体の見かけの大きさを維持する。

## 6. 8フレーム化

8フレームが必要な場合は、4キーポーズとは別に4つの中割りポーズを2×2で生成する。

中割りボードの配置順:

1. 左上: `rest-to-anticipation`
2. 右上: `anticipation-to-peak`
3. 左下: `peak-to-return`
4. 右下: `return-to-rest`

最終順序:

1. `rest`
2. `rest-to-anticipation`
3. `anticipation`
4. `anticipation-to-peak`
5. `peak`
6. `peak-to-return`
7. `return`
8. `return-to-rest`

中割りは、前後ポーズの形状、重心、手足、髪、衣服、所持品の中間になるように生成する。

## 7. 複数状態

複数の状態または動作を求められた場合は、1動作につき1枚の2×2キーポーズボードを生成する。

最初から複数動作を一枚の巨大なスプライトシートへ配置しない。状態ごとに生成、分離、正規化、監査し、合格したストリップだけを後段でまとめる。

## 8. 公式互換8×9アトラス

ユーザーが「公式互換」「8×9」「9状態」「pet atlas」などを指定した場合でも、画像生成段階では状態ごとの2×2キーポーズボードを作る。

最終アトラス規格:

- キャンバス: 1536 × 1872 px
- 列数: 8
- 行数: 9
- セル: 192 × 208 px
- 1状態あたり: 8フレーム
- フレーム方向: 左から右
- 背景: 完全透過

標準行順:

1. `idle`
2. `running-right`
3. `running-left`
4. `waving`
5. `jumping`
6. `failed`
7. `waiting`
8. `running`
9. `review`

この最終配置は画像生成モデルではなく、組み立て処理で行う。

## 9. テンプレート画像

テンプレート画像は最終配置の参照にだけ使う。

参照する情報:

- 行数と列数
- セル寸法
- キャンバス比率
- 配置順

最終画像へ残さないもの:

- グリッド線
- 枠線
- 行名
- 番号
- 説明文字
- 完成例のキャラクター
- チェック柄背景

キャラクターの見た目は基準キャラクター画像だけから取る。

## 10. 組み立てコマンド

4キーポーズから4フレームを作る例:

```bash
python audit/scripts/build_motion_strip.py keyposes.png \
  --spec audit/specs/motion-keypose-2x2.json \
  --output motion-4f.png \
  --debug-dir motion-debug
```

キーポーズと中割りから8フレームを作る例:

```bash
python audit/scripts/build_motion_strip.py keyposes.png \
  --inbetween-board inbetweens.png \
  --spec audit/specs/motion-keypose-2x2.json \
  --output motion-8f.png \
  --debug-dir motion-debug
```

組み立て処理は、透明背景、空ポーズ、セル端接触を検査し、全ポーズへ同じ倍率を適用する。

## 11. 出力確認

キーポーズボードでは次を確認する。

1. 4象限に1ポーズずつある
2. 順序が正しい
3. ポーズが象限境界をまたいでいない
4. 全身と付随物が切れていない
5. 同じキャラクターとして読める
6. 顔、髪、衣装、配色、装飾が共通している
7. 全ポーズのカメラ角度と縮尺が近い
8. 背景が完全透過である
9. 枠線、番号、不要な文字がない

最終ストリップでは次を確認する。

1. フレームが時間順に並んでいる
2. 全フレームで共通倍率が使われている
3. 基準位置とセル余白が揃っている
4. セル境界で切れていない
5. 固有パーツと所持品が途中で消えていない
6. 先頭と末尾が自然につながる
7. 同じ画像の複製で水増しされていない
