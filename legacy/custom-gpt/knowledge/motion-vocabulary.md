# Motion vocabulary

この文書は、状態名から視覚的な動作を設計するための参照資料である。

各項目は固定振付ではない。基準キャラクターの体格、衣装、所持品に合わせて調整する。

## 動作設計の基本単位

モーションは、次の3段階を含むと読み取りやすい。

1. 準備: 動作へ入る前の小さな予備動作
2. 主動作: 状態を最も明確に示す姿勢
3. 戻り: 先頭フレームへ自然につながる復帰

髪、衣服、尾、ケーブル、札、所持品などは、身体より少し遅れて追従させる。

## 基本状態

### idle / 待機

- 小さな呼吸
- 瞬き
- わずかな重心移動
- 髪や衣服の控えめな揺れ

大きな移動をさせず、先頭と末尾を自然につなぐ。

### waving / 手を振る

- 手を上げる
- 手首または前腕を左右へ振る
- 視線を相手へ向ける
- 最後に手を基準位置へ戻す

腕全体を大きく振る場合も、肩の位置と身体の軸を安定させる。

### running-right / 右へ走る

- 身体を右方向へわずかに傾ける
- 腕と脚を交互に動かす
- 接地、沈み込み、蹴り出し、滞空を含める
- 髪や衣服を進行方向と逆へ遅らせる

### running-left / 左へ走る

`running-right`を単純反転しただけにせず、左右非対称の衣装と装飾を正しく維持する。

### jumping / 跳ぶ

- しゃがみ込み
- 蹴り出し
- 上昇
- 頂点
- 下降
- 着地

足元の影や床は、ユーザーが必要とした場合だけ加える。

### waiting / 入力待ち

- ユーザー側へ注意を向ける
- 静かな呼吸と瞬き
- 小さな首や視線の動き
- 急かさない姿勢

### failed / 失敗

- 問題に気づく
- 表示や手元を見直す
- 肩や視線がわずかに落ちる
- 再確認する姿勢へ戻る

過度な悲嘆や転倒にしない限り、控えめな反応を基本にする。

### review / 確認

- 資料、画面、対象を見比べる
- 視線を左右または上下へ移す
- 最後に小さくうなずく、または確認姿勢で止まる

## 作業状態

### searching / 検索

- 画面、資料、カードを順に送る
- 視線で結果を追う
- 一件を見つけて一瞬止まる
- 再び検索姿勢へ戻る

### reading / 読込

- 文書や画面へ視線を向ける
- 行を追うように目を動かす
- 小さなページ送りやスクロール

### thinking / 思考

- 視線を外す
- 顎、口元、こめかみ付近へ手を添える
- 短い停止
- 考えがまとまり視線を戻す

### calculating / 演算

- 指先入力
- 表示や回路の順次変化
- 数値や情報を追う視線
- 計算完了時の小さな反応

不要な数式や読めない文字を勝手に描かない。

### validating / 検証

- 二つ以上の情報を交互に確認する
- 差異を見つける
- 最後に一致または不一致を示す小さな反応

### comparing / 比較

- 左右の対象へ視線を往復させる
- 必要なら手や指で対応関係を示す
- 両方を同時に見渡す姿勢で終える

### organizing / 整理

- 資料やカードを分類する
- 並び替える
- 位置を整える
- 最後に全体を確認する

### completed / 完了

- 作業姿勢から身体を戻す
- 小さくうなずく
- 控えめな笑顔または達成反応
- 完了状態を短く示した後、待機姿勢へ戻る

## 感情・反応

### confused / 困惑

- 一度見直す
- 視線を往復させる
- わずかに首を傾ける
- 眉や口で軽い疑問を示す

### surprised / 驚き

- 目を開く
- 身体を少し引く
- 手や肩が遅れて反応する
- 急激すぎない形で基準姿勢へ戻る

### happy / 喜び

- 表情を明るくする
- 身体が少し上向く
- 手や肩で控えめな達成感を示す

### sad / 落胆

- 視線が下がる
- 肩が少し落ちる
- 動きを小さくする

キャラクターの通常の性格表現を壊すほど大げさにしない。

## キャラクター固有物との連動

### 札・表示板

- 本体と取り付け位置を維持する
- 身体の動きに伴って少し遅れて揺らす
- ユーザーが文字を指定しない限り、新しい文字を加えない

### 尾・翼・ケーブル

- 根元の位置を固定する
- 身体の加速と減速に遅れて動かす
- フレーム途中で長さや本数を変えない

### 発光・回路

- 元画像にある発光だけを維持する
- 状態表現として変化させる場合も、色と配置を保つ
- 身体から離れた粒子や記号は必要な場合だけ使う

## 避ける動作

- 同じ姿勢を複製しただけのフレーム列
- フレームごとにカメラ角度が変わる動き
- 関節の向きが不連続に反転する動き
- 所持品や装飾が途中で消える動き
- 状態として読み取れない小さすぎる変化
- キャラクターの性格や体格を無視した過剰な演技
