# Prompt Examples

## 単一状態

```text
添付画像を唯一のデザイン正本として、このキャラクターが空中ディスプレイで検索する8フレームの横一列ループアニメーションを生成して。顔、髪、衣装、配色、装飾、頭身を維持。背景は完全透過。
```

## 状態名だけで生成

```text
このキャラクターのvalidatingを8フレームで作って。
```

## 複数状態を個別画像で生成

```text
このキャラクターについて、searching、reading、calculatingの3状態を作って。各状態は別画像、8フレーム横一列、透過背景、自然なループ。
```

## テンプレートへ複数状態を配置

```text
1枚目をキャラクターの正本、2枚目を8列×9行の配置テンプレートとして使って。

1行目: searching
2行目: reading
3行目: calculating
4行目: validating
5行目: requesting-input
6行目: confused
7行目: error
8行目: completed
9行目: organizing

各行8フレームの独立したループ。全行で縮尺、足元、セル寸法を統一。背景と未使用部分は完全透過。テンプレートのグリッド線は最終画像へ残さない。
```

## 動作を具体化する

```text
searchingを8フレームで生成して。空中に二枚の半透明画面を表示し、右手で検索結果を送る。視線は画面を追う。髪と札は動作に少し遅れて揺れる。最終フレームから第1フレームへ自然に戻る。
```

## 同じ状態を複数案

```text
このキャラクターのthinkingアニメーションを3案作って。各案8フレーム、別画像、控えめな動作、透過背景。
```

## 行単位の修正

```text
3行目のcalculatingだけ修正して。手の形を自然にし、回路表示が順番に点灯する動作へ変更。ほかの行、顔、衣装、配色、縮尺、セル寸法は維持して。
```

## 一部分だけ修正

```text
第5〜第7フレームで札が消えている。札だけ復元して。動作、表情、手の位置、背景、ほかのフレームは変更しない。
```

## 画像生成をしない設計相談

```text
画像は生成せず、このキャラクターに合う追加状態を9種類設計して。各状態について、状態名、発火場面、8フレーム内の動作を示して。
```
