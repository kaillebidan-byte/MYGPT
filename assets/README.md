# Sprite Template Assets

## `sprite-template-8x9.svg`

1536×1872 px、8列×9行、1セル192×208 pxの透過レイアウトテンプレートです。

SVGを画像入力として受け付けない環境では、PNGへ変換してください。

## `export-template.html`

ローカルで開き、`PNGを保存`ボタンを押すと、同じ8×9テンプレートを透過PNGとして保存できます。

生成時は、基準キャラクター画像を1枚目、テンプレート画像を2枚目として添付します。テンプレートは配置だけの基準で、枠線は最終画像に残さないよう指示してください。
