# Templates

`pet-atlas-template-8x9.png`は、公式互換アトラスの配置だけを示す参照画像。

- キャンバス: 1536 × 1872 px
- 8列 × 9行
- 1セル: 192 × 208 px
- 行順: idle / running-right / running-left / waving / jumping / failed / waiting / running / review

生成時は、基準キャラクター画像とこのテンプレートを同時に添付する。テンプレートはレイアウトだけに使い、最終出力へ枠線、行名、番号、背景を残さない。

一括生成では崩れやすいため、最初は2〜4行で試し、安定した場合に9行へ増やす。
