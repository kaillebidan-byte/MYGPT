## CURRENT実装方針

一つの既存拡張を丸ごと改造しない。
独立した `MYGPT Worker Fanout` extensionを新設し、3者の良い部分だけ合成する。

- control plane: Translation Loop型
- observer/route watching: VoiceBridge型
- canonical file attachment/new-chat UI primitive: AutoGPTで確認した方式をclean-room実装

禁止:
- ChatGPT internal API
- Bearer token
- response interception
- output scraping/download
- CSP/security-header removal
- visibility spoof
- telemetry
- external upload
- auto retry

## 次チャットで最初にやる作業

1. repoに独立 `MYGPT Worker Fanout` extension directoryを作る。
2. current Custom GPT pageからnormalized `/g/...` worker identityを取るroute adapterを実装。

6. Gate 0ではprompt insertion、canonical attachment、sendを一切しない。
7. Vivaldi用のload-unpacked / live test手順を作る。

- packet insert without submit
- canonical attach without submit
- one-tab prepared state
- exactly 3 tabs fan-out
- controlled submit
- known single image invocation
- 3-worker actual generation
の順で進む。
